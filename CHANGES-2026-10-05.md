# Changes — 2026-10-05 review of the first live paper day

Found by reviewing the 2026-10-05 Hermes run (77 cycles, 1 TXN entry, EOD learning run).
All changes have regression tests that fail on the previous code. Suite: 198 passed.

## Fixed

1. **Jev confidence gate was "retry until yes"** (`engine.py`, `jev.decide_once_per_day`).
   Jev (TypeSafe) is stochastic: the identical TXN signal scored 0.12 → 0.04 → 0.33 → 0.57 →
   0.67 on five consecutive 5-min cycles and the trade fired on the one that crossed 0.60.
   A fresh signal stays live ~3 days (≈230 cycles), so the gate passes by chance. Held
   positions had the same exposure (49 "sell" verdicts at 0.01–0.50 today — one lucky roll
   ≥0.60 would have sold on noise). Now: one verdict per symbol per day for entries and for
   held-position reviews (`journal/cache/jev_verdicts_<date>.json`). An approved buy that
   could not execute (market closed / risk / order error) is retried without re-asking.
   This also stops the decision-policy learner seeing a "vetoed" and a "taken" forecast for
   the same symbol on the same day (today's TXN), which contaminated the veto evaluation.

2. **Live stop ≠ backtested stop** (`engine.py`). The TypeSafe adapter hard-codes
   `stop = close × 0.97`, and the engine preferred Jev's stop. Every live trade got a 3%
   stop while backtests/learning validate 3×ATR (TXN: $280.93 vs ≈$270). The strategy's
   own `initial_stop()` is now used; Jev's is only a fallback.
   *The open TXN position keeps its $280.93 broker stop (stops only ratchet up).*

3. **Alpaca bars were unadjusted** (`data.py`). No `adjustment=` → Alpaca default RAW, so
   splits (NVDA, AVGO 10:1 in 2024) look like −90% crashes to SMAs, ATR and learning
   backtests. Now `Adjustment.ALL`.

4. **Learning windows silently shrank** (`config.yaml`, `learning/loop.py`).
   `history_days: 1500` gave ≈1030 bars < the 1068 needed for 252/378/378, so
   `window_bounds` fell back to proportional splits: today's "3-year" scored window was
   412 days (2025-02-13 → 2026-10-05). Raised to 1900 and the fallback now logs a warning.

5. **Advisor transient failures not retried** (`advisor.py`). "JSONDecodeError: Expecting
   value" (2 of today's advisor calls) came from the SDK decoding an empty NVIDIA gateway
   body, outside the existing JSON retry. Transport/decode/5xx errors now retry once.

6. **Dashboard** (`dashboard/render.py`): SPY line missing (equity curve starts on a
   Sunday; SPY cached pre-open) → as-of join + 30-min SPY cache; y-axis ticks all read
   "100" on small ranges → adaptive precision.
