# Baseline Strategy: SMA Crossover (v1.0)

## Description
Simple Moving Average Crossover.
- Buy when the 20-day SMA crosses above the 50-day SMA
- Sell when the 20-day SMA crosses below the 50-day SMA

## Rationale
This is the simplest trend-following strategy. It serves as a validation
baseline for the data pipeline before adding complexity.

## Data Sources
- Historical: yfinance (free, backfill-grade)
- Real-time: Alpaca (authoritative for live data)

## Risk Limits (from config.yaml)
- Per-trade max loss: 2%
- Total open exposure: 10%
- Daily loss limit: 5%
- Drawdown halt: 15%
